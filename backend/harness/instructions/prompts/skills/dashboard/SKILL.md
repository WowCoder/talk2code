# 数据看板规范

## P0 图表必须手写，禁止引 CDN

运行环境没有网络，**Chart.js / ECharts / D3 全部不可用**。
引入外部 CDN 会让整个图表区空白，且控制台报加载失败。

用原生 SVG 手绘（推荐，缩放清晰、可加交互）或 Canvas 2D：
- 柱状图 / 条形图：`<rect>` 按数值算高度
- 折线图：`<polyline>` 的 points 由数据算坐标
- 饼图 / 环形图：用 `<path>` 画扇形，或 `stroke-dasharray` 画环

```js
// 柱状图核心：把数值线性映射到像素高度
function barHeight(value, max, h) {
  return max > 0 ? Math.round((value / max) * h) : 0;
}
```

SVG 用 `document.createElementNS('http://www.w3.org/2000/svg', 'rect')` 创建，
**不是** `createElement`——用错 API 元素不会渲染，且不报错。

## P0 容器尺寸不能为 0

在 DOM 未布局完成（或容器被 `display:none` 包裹）时读 `clientWidth` 会得到 0，
图表算出来的坐标全是 0，结果是一片空白。

对策（二选一）：
1. 图表用**固定的 viewBox + `width="100%"`**，靠 SVG 自身缩放，不去读容器像素；
2. 若必须读尺寸，放到 `DOMContentLoaded` 之后，并给 0 值兜底：
   `var w = el.clientWidth || 600;`

## P0 空数据态

没有数据时不能什么都不画。给出空态提示，并且**坐标轴 / 图例仍然渲染**
（让用户知道这里本来该有什么）：

```js
if (!data.length) {
  chart.innerHTML = '<text x="50%" y="50%" text-anchor="middle">暂无数据</text>';
  return;
}
```

## P1 数值与格式的边界

- 最大值用于归一化，要防 0 和全等值（`max === min` 时柱状图高度全满或全空）
- 数值标签做千分位与单位格式化（`1.2k` / `12.3%`）
- 负数（涨跌、盈亏）要有独立的方向与配色，不能和正数画在同一基线下方还看不出区别

## P1 内置示例数据

纯前端没有数据源，**必须在 `js/data.js` 里内置一份示例数据集**，
页面打开就有内容可看。同时提供"重新生成示例数据"按钮，
让筛选和联动有东西可操作。

## P1 筛选联动

筛选器（时间范围、分类下拉）变更后：
1. 重算派生数据；
2. 重新渲染**所有**受影响的图表（只更新一个会给人"数据没变"的错觉）；
3. 更新汇总卡片（总数、均值、环比）。

筛选到空结果时，图表走上面说的空数据态，不要保留上一轮的图形。

## 自验收清单

- [ ] 页面打开就有图，不是空白（内置示例数据已生效）
- [ ] 没有引用任何外部 CDN（全文搜 `https://` 应为 0 命中）
- [ ] 切换筛选 → 所有图表同步更新
- [ ] 筛选到无结果 → 显示空态提示
- [ ] 控制台无报错，SVG 元素用 `createElementNS` 创建
