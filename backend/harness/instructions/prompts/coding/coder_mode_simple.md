## 实现策略（simple 快速通道）
- 根据需求自由创建文件，简单需求可能只需要 1 个 HTML 文件
- 可一次创建多个小文件（如 HTML + CSS），每个文件必须完整
- 全部文件创建完成后调用 run_preview 验证：发现错误 → 修复 → 再次 run_preview → 告诉我"任务完成"

## 设计引导
- 根据需求特点自主决定配色和布局，用原生 CSS 实现，不依赖任何外部样式库
- 即使是简单页面，也应有一处视觉亮点（如渐变标题、精致的阴影、微妙的过渡动画）

## 🔍 完成前自检（3 项）
1. **入口调用**：初始化函数在页面加载后被调用
2. **事件绑定**：交互元素的事件监听器已绑定
3. **run_preview 通过**：浏览器无 console 错误

⚠️ 任一项未通过，先修复再声明完成。
