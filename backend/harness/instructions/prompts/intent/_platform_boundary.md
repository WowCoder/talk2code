### 平台能力边界

本平台产出的是一个**纯静态前端站点**：单个 index.html 入口 + 本地 css/js，
直接双击就能打开，没有服务器、没有数据库、不联网。数据只存在浏览器本地
（localStorage / IndexedDB）——换一台设备或换一个浏览器就看不到之前的数据。

**做不到**：
- 真实的服务端数据库、用户注册登录账号体系、跨设备数据同步
- 后端接口、服务端渲染、WebSocket 实时通信
- 调用第三方 API 密钥的服务、支付、短信、邮件发送
- 爬虫、定时任务、服务端文件处理

**可以做**：本地存储的个人数据管理、内置示例数据的演示型站点、
完整的界面与交互逻辑、纯前端的计算与可视化。

**关键区分**：用户说"要后端"，往往真实意图是"数据要存下来""要能多人看到"。
凡是能用浏览器本地存储等价满足的，就**不是**能力外的需求。

- "做个待办清单，能保存我的任务" → 能做（localStorage 就够了）
- "做个博客，能发文章" → 能做（本地存储 + 模拟数据即可演示）
- "做个系统，用户注册后在任何设备都能登录看到自己的数据" → 做不到（必须服务端）
- "做个后台管理，连 MySQL 读真实订单数据" → 做不到
- "做个聊天室，两个人能互相发消息" → 做不到（需要服务端中转）
